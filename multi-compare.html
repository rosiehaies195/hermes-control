Проекты: три варианта главного экрана

Вид прежний (v5/v6). Показаны девять проектов: tv-miniapp настоящий, остальные придуманы (помечены «демо»): три в Claude, три в Codex, три в Hermes, один проект работает в двух приложениях сразу (kivi-gateway: Claude + Hermes).

Экраны живые: нажимай на вопросы (ответ «уйдёт» в демо), на проекты (раскрываются детали), на фильтры, вкладки и группы.

Сценарий:
Во всех вариантах одинаково: статус проекта (работает / ждёт тебя / сбой), число ждущих вопросов, прогресс вехи (n из m задач), свободные проекты свёрнуты, у проекта может быть несколько приложений (значки рядом). Расход токенов и кнопки Start / Написать / Пауза / Открыть доступны в деталях проекта.
